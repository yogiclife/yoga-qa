**Original Question:**  
जीवात्मापरमात्मनोः

**Full Answer:**  
So samAsas are made from the prAtipadikam, which here is जीवात्मन्‌ | Then there is नकारलोपः, so it becomes जीवात्म + परमात्मन्‌ + vibhakti => जीवात्मपरमात्मनोः
