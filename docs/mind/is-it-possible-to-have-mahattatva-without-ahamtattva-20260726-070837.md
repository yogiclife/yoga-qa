**Original Question:**  
when a jiiva begins to feel it is a separate being-- when it has only mahattattva, or when ahamtattva becomes present? 

**Full Answer:**  
This question is asking about a scenario which does not exist. There is no jiiva which has mahattattva but does not yet have ahamtattva. Any jiiva which has an active mahattattva already had an active ahamtattva even before it had an active mahattattva.
