**Original Question:**  
For the living beings when the karma will be start functioning. We can take it from alage stage onwards"

**Full Answer:**  
Karma is action, and all jivas are involved in some actions. Karma phala is the spiritual consequences of the action -- papa and punya. Only humans experience it because humans alone have free will. Of course, non-physical consequences of action apply to all. For example, if an insect enters fire, it will burn.
