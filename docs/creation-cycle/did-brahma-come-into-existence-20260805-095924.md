**Original Question:**  
Did Brahma come into existence?

**Full Answer:**  
You said that beyond srsti karya-karana bhava does not apply, and in that context there is one question we cannot answer, and other questions we can answer. So you asked X ji what is the question we cannot answer. X  ji said the question we cannot answer is "How did the Infinite Supreme Entity come into existence". And you accepted her answer, and tried to make it reasonable by saying, that yes, that is true, in the sense that It did not come into existence. But I just would like to point out here-- and this is a point that regards all our teachers really-- is that if a student says something that is wrong, then there is no harm in saying so. It can be said in a supportive way, it is not that we are cutting the person down. But if something is wrong then they need to know that it is wrong. That is how people learn. So when X ji said that, then as a teacher we should tell her that that is not the answer. The question "How did the Infinite Supreme Entity come into existence" is itself wrong and nonsensical, as the Infinite Supreme Entity did not ever "come into existence" as it is anadi, it is infinite. We can only ask a question "how....?" about something that actually happened. And the "coming into existence" of the Infinite Supreme Entity never happened. Whereas we can indeed talk about the beginning of the srsti. And yes, it is true that it was always being created, but even then we can talk about its beginning as, in a sense, it is always beginning. So how does that beginning step happen. There we can ask "how...?", we can ask "why....?" And it is that question which is beyond karya-karana bhava and so cannot be answered. Not the one which X ji suggested.
